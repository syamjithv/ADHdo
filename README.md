## 🌷 About

**ADHdo!** is an AI-powered productivity companion designed specifically for students and individuals with ADHD, executive dysfunction, analysis paralysis, and task-initiation hurdles. 

Traditional to-do apps often induce guilt and cognitive overload by presenting giant walls of text. ADHdo! flips the script: it breaks down intimidating walls into micro-actions, coaches you past start-up friction, and keeps you moving forward without pressure or shame.

### 🎯 What Makes ADHdo! Different?

Traditional productivity tools often focus on tracking tasks and checking off lists. ADHdo! explores a more supportive approach: helping users navigate the moments when they feel stuck, overwhelmed, or unsure what to do next.

### 💡 Our Philosophy

You don't need a perfect routine to make progress. You don't have to finish everything today. Sometimes, the most important thing is simply finding a first step that feels possible.

ADHdo! is built around that idea.

**Less overwhelm. Smaller steps. Tiny wins.**

Because getting started should feel ADH-doable! 💜

## ✨ Features

- 💜 **Compassion-First Design:** A supportive experience built around flexibility, self-kindness, and progress over perfection—never guilt or shame.
- 🪄 **Unstuck Mode:** AI-driven micro-breakdowns that decompose ambiguous tasks (e.g., *"Clean room"*) into frictionless, single-click mini steps (e.g., *"Pick up 3 pieces of trash"*)
- 🧩 **Help Me Start:** A low-friction launchpad designed to overcome activation inertia by isolating the easiest possible 2-minute entry point.
- ⏳ **Adaptive Focus Timer:** Flexible, dopamine-friendly focus intervals with gentle re-engagement cues rather than punitive deadlines.
- 🏠 **My Day View:** A clean, clutter-free dashboard displaying only what is actionable right now—hiding overwhelming backlog items until you're ready.
- 🛡️ **Zero-Guilt Architecture:** No overdue task red alerts, failure streaks, or pressure-driven badges.
- 🤖 **ADHdo Buddy:** Your AI-powered productivity companion that helps untangle thoughts, break down overwhelming tasks, brainstorm next steps, and find a manageable way forward through supportive, judgment-free conversations.

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.17 or higher)
- [npm](https://www.npmjs.com/), `pnpm`, or `yarn`
- An AI Provider API key (e.g., OpenAI or Google Gemini)

### Installation

### 🚀 Step 1: Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/syamjithv/ADHdo.git
cd ADHdo
```

### 📦 Step 2: Install Dependencies

If the project contains a `package.json` file, install its dependencies:

```bash
npm install
```

### 🔑 Step 3: Configure Environment Variables

If the application requires API keys or environment variables:

1. Check the project documentation for the required variable names.
2. Create a local `.env` file if needed.
3. Add your own API keys and configuration values.

**Security:** Never commit API keys, passwords, or other secrets to GitHub.

### ▶️ Step 4: Run the Application

If the project uses Vite and defines a development script, run:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 🧩 Troubleshooting

- **Git not found:** Install Git and reopen your terminal.
- **npm not found:** Install Node.js if required by the project.
- **Dependency errors:** Check the project's dependencies and documentation.
- **Application won't start:** Review the terminal output for error messages.
