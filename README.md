🌷 About ADHdo!
ADHdo! is an AI-powered productivity companion designed to help people get unstuck when tasks feel overwhelming, starting feels difficult, or distractions interrupt their flow.
Instead of simply organising another to-do list, ADHdo! helps you understand what's getting in the way and find a manageable next action.
💜 You don't always need a better plan. Sometimes, you need a smaller first step.
✨ Features
🪄 Unstuck Mode — Find a practical next step when you're overwhelmed, distracted, or low on energy.
🧩 Help Me Start — Break intimidating tasks into smaller, actionable steps.
🗓️ My Day — Organise tasks and track daily progress.
⏳ Focus Timer — Work in manageable focus sessions.
🛟 Bring Me Back — Return to your task after an interruption.
🧠 Untangle My Brain — Organise thoughts into tasks, ideas, and reminders.
🔄 Adapt My Day — Reconsider priorities when plans change.
💬 ADHdo Buddy — Talk through what's blocking you with AI-powered assistance.
🌱 Tiny Wins & Rewards — Celebrate meaningful progress, including small starts.

🚀 Getting Started
Prerequisites
Node.js
npm
A Gemini API key, if required for AI features
Installation
1. Clone the repository
git clone YOUR_REPOSITORY_URL
2. Enter the project directory
cd YOUR_PROJECT_DIRECTORY
3. Install dependencies
npm install
4. Configure environment variables
Configure any required API keys using your server-side environment setup.
Security: Never commit API keys to GitHub or expose private keys in client-side code.
5. Start the development server
npm run dev
6. Build for production
npm run build
🌐 Deployment
ADHdo! is intended to be deployable on platforms such as Vercel.
Push the project to GitHub.
Import the repository into Vercel.
Configure the required environment variables.
Deploy the application.
Test the deployed site and its AI-powered features.
🔐 Privacy
ADHdo! may store supported tasks and progress in browser local storage.
Local data is generally specific to the current browser and device.
Data does not automatically synchronise across devices unless synchronisation is implemented.
AI-powered features may send relevant user-provided text to the configured AI service.
Avoid submitting sensitive personal information.
