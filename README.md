🌷 About
ADHdo! is an AI-powered productivity companion that helps people get unstuck when tasks feel overwhelming, starting feels difficult, or distractions interrupt their flow.
💜 You don't always need a better plan. Sometimes, you need a smaller first step.

✨ Features
🪄 Unstuck Mode — Find a practical next step.
🧩 Help Me Start — Break big tasks into smaller actions.
🗓️ My Day — Organise tasks and track progress.
⏳ Focus Timer — Work in manageable sessions.
🛟 Bring Me Back — Return to a task after interruptions.
🧠 Untangle My Brain — Organise thoughts and ideas.
🔄 Adapt My Day — Reconsider priorities.
💬 ADHdo Buddy — Conversational AI assistance.
🌱 Tiny Wins & Rewards — Celebrate meaningful progress.

🚀 Getting Started
Prerequisites
Node.js
npm
Installation
1. Clone the repository
git clone YOUR_REPOSITORY_URL
2. Enter the project folder
cd YOUR_PROJECT_DIRECTORY
3. Install dependencies
npm install
4. Start the application
npm run dev
5. Build for production
npm run build
Configure any required Gemini API key using the project's secure server-side setup. Never publish private API keys.

🌐 Deployment
ADHdo! is intended to be deployable on Vercel.
Push the repository to GitHub.
Import it into Vercel.
Configure required environment variables.
Deploy and test the application.

🔐 Privacy
Supported tasks and progress may be saved in browser local storage.
Local data does not automatically synchronise between devices.
AI features may send relevant prompts to the configured AI provider.
Avoid entering sensitive personal information.
