🌷 What is ADHdo!?
ADHdo! is an AI-powered productivity companion designed to help people get unstuck when tasks feel overwhelming, starting feels impossible, or distractions interrupt their flow.
Instead of giving you another endless to-do list, ADHdo! helps you figure out what's getting in the way — and what you can do next.
✨ You don't always need a better plan. Sometimes, you need a smaller first step.

🌐 Deployment
ADHdo! is intended to be deployable using platforms such as Vercel.
Push the code to GitHub.
Import the repository into Vercel.
Configure the required environment variables.
Deploy and test the live application.
🔐 Privacy
ADHdo! may store supported tasks and progress in browser local storage. This data is generally limited to the browser and device unless additional synchronisation is implemented.
AI features may transmit relevant prompts to the configured AI provider. Avoid submitting sensitive personal information.
